# Coding Rule
 ## Avoid Bug
  - **Trước khi sửa:** Anhnt đóng tab file trong MetaEditor (MetaEditor không tự reload, buffer cũ sẽ đè lên) 
  - **String có `;` trong parameter của method:** không viết string có `;` ngay trong method call (vd `EventSend(..., ::Symbol()+";"+magic)`); syntax highlight của IDE sai từ đó tới hết file.
   + Ghép string vào local variable trước rồi truyền variable: `string target=::Symbol(); target+=";"; target+=magic; this.EventSend(...,target);`
   + Sau khi sửa MQL5, grep các file vừa đụng theo `\(.*"[^"]*;[^"]*".*\)` và tách string đó ra local variable.
  - **View chỉ làm phần thay đổi và phần đang hiện** (đo 2026-11-26: EA treo 1–14 s, cả máy "lơ ngơ"). Hàm hỏi chart (`ChartSymbol`, `ChartPeriod`, `ChartGetInteger`, `ObjectGet*`, `ObjectFind`) đợi chart xử lý xong hàng đợi mới trả về; vẽ canvas (`Draw`, `m_canvas.Update`) và tạo object native đẩy thêm việc vào hàng đợi đó. Làm dồn thì treo EA.
   + Không cache symbol / TF của chart lúc init: với EA, `REASON_CHARTCHANGE` giữ nguyên global.
   + Mẫu cụ thể nằm ở AGENTS.md của thư mục sở hữu: [Collections](../../Library/Collections/AGENTS.md), [GBases](../../Library/Entities/GBases/AGENTS.md), [Controls](../../Library/Entities/Controls/AGENTS.md), [Graph Composite](../../Library/Entities/Graph/Composite/AGENTS.md), [GUIPannel](../../Experts/Anhnt/Example%20EA/4.%20Combination%20EA%20V5/GUIPannel/AGENTS.md).
  - **[Chart Channel](../Notes/Event.md#system-concept-event-channel):** gồm Event terminal tự sinh (chuột, phím, `CHARTEVENT_CHART_CHANGE`, object) và Event custom gửi bằng `::EventChartCustom`. Phải chờ chart xử lý hết hàng đợi (như hàm hỏi chart ở trên); mất Event gửi trong `OnTrade` (lỗi 4104).

 ## Tìm caller <a id="codingRule-Trick-Callfind">
  - Comment out method nghi ngờ (hoặc đổi signature) rồi compile: compiler chỉ ra mọi caller, không phải search cả Library. Không còn caller thì xoá và dọn luôn phần nó để lại (header box, comment mô tả cách cũ).

 ## Debug print
  **Bug runtime**
   - Đặt `::Print("MY DEBUG CClass::Method: …")` trong chính hàm nghi ngờ; tránh Print debug chung chung sau này ko biết chỗ mà dọn dẹp.  
   - Ghi file chỉ vào `MQL5\Files\<program>\` qua `GetFolderName()`.
   - Không ghi file debug ở Event mỗi tick (`TICK_EVENT_NEW`, `ACCOUNT_EVENT_PROPERTY_CHANGED`): mở / ghi file mỗi lần làm nghẽn bus (mẫu `Breadcrumb` trong `DispatchEvent`).
  **Log sources:**
   - Experts tab: `MQL5\Logs\YYYYMMDD.log`.
   - Journal tab (lỗi trade): `Logs\YYYYMMDD.log`.
  + Chủ động grep đọc kết quả qua, không yêu cầu dán log.
  **Bug nằm trong một Control:** dựng test EA tối giản. 
 ## Folding Rule
  Goal của Folding Rule là cần đọc cho thuận tiện bằng việc căn lề và được áp dụng ở mọi nơi miễn là đúng cú pháp.
  - **Code (MQL5):**
   + Mỗi khối (`#ifndef`/`#endif`, class, method, `if`/`for`/`switch`) thụt sâu hơn khối cha một bậc; dấu đóng (`}`, `#endif`) thẳng cột với dấu mở.
   + Theo cách thụt lề sẵn có của file; file mới theo mẫu `RiskSetting.mqh`.
  - **Markdown:** lấy luôn file này làm mẫu.
 ## Comment in Code
  - Mục tiêu của comment là giữ [Document](../AGENTS.md#skills-and-document) ngắn gọn trong code để đạt [Rule Gate](../AGENTS.md#rules-gate-mục-tiêu-xuyên-suốt).
  **Comment của agent:** Comment bằng tiếng Anh
  **Header class/file:** theo khung `//+---+`:
   - Vai trò; ai ghi/đọc data (DB, table); event fire/nghe kèm dparam/sparam.
   - Nguồn Reference và method không port kèm lý do.
  **Header method:** Theo khung `//+---+`.
  **Note của Anhnt:** trong code (header file, dòng `// Update in V4…`) agent chỉ đọc, không sửa, không xoá.
  **Trạng thái:** `[]` là việc chưa xong, `[v]` là đã xong; đưa `[]` vào danh sách rà soát.
  - Member một comment cuối dòng.
  **Comment conflict::**- Nếu phát hiện comment mâu thuẫn với code hoặc Rule Gate, hoặc không phù hợp với ngữ cảnh, nêu rõ vị trí và căn cứ để trao đổi lại không tự ý thay đổi.
 ## File Structure
  - **Cấu trúc class và file:**
   + Mỗi class một file, có include guard.
   + Tách rõ Declaration và Implementation guard → declaration → implementation, getter/setter chỉ viết inline khi ngắn gọn. 
  - Các class chứa data khai báo theo [DoEasy Data Object](../Notes/Concepts.md#doeasy-data-object)
   + Thêm property = thêm 1 giá trị enum; không dùng mảng key-value tìm theo string, không gọi property bằng tên string.
  - Module (class lớn tách nhiều file): `<Class>_Define.mqh`, `<Class>.mqh`, `<Class>_Lifecycle.mqh`, `<Class>_Window_<Name>.mqh`; mẫu `GUIPannel\`.
 ## Check Inherit
  - Kiểm tra tính kế thừa cho properties và method.
   + [Bases](../AGENTS.md#mt5-library-base-objects): `CBaseObj` (type, `EventSend`); Pure Data kế thừa trực tiếp.
   + [GBases](../AGENTS.md#mt5-library-base-graphic-objects): `CGBaseObj : CBaseObj`, thêm Parent-Child (`AddChild`).
   + [Controls](../AGENTS.md#mt5-library-gui-control-object): `CGElement : CGBaseObj`.
   + **Refresh:** không override `CBaseObjExt::Refresh`; đặt tên `RefreshX` (RefreshSeries, RefreshAccount…).
  - Kiểm tra enum đã có trong 
   + [Enum and Define](../AGENTS.md#mt5-library-enum-define) trước khi khai mới.
   + `D:\MT5-Dev\Experts\Anhnt\Example EA\4. Combination EA V5\GUIPannelGUIPannel_Define.mqh` 
  - Tránh [DRY — Don't Repeat Yourself](../AGENTS.md#dry).
